# Deep cuts

Cases of ours that the selection rule did not keep: each reaches nothing the selected and upstream cases do not, or only what a smaller case also reaches. They are kept, by source, as extra data for testing implementations, with the same manifest format as `sets/`. `docs/coverage.md` ("Why each case is here") says how they were chosen, and each row's `purpose` and `why` say why this one is here. `scripts/verify` runs them unless `--sets` says otherwise.
